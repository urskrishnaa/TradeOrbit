# TradeOrbit — Cryptocurrency Tracker

A cryptocurrency tracking app built with React, Material UI, and Chart.js. Browse live prices, market caps, and 24h trends for the top coins, search for a specific coin, and view historical price charts across multiple timeframes.

## Built with

- [React JS](https://reactjs.org/)
- [Material UI](https://v4.mui.com/)
- [Chart JS](https://reactchartjs.github.io/react-chartjs-2/#/)
- [CoinGecko API](https://www.coingecko.com/en/api)

## Getting started

```bash
yarn install
yarn start
```

The app runs at `http://localhost:3000`.

## Features

- Live prices, market cap, and 24h change for the top 100 coins by market cap
- Search and pagination
- Trending coins carousel
- Per-coin detail page with historical price chart (24h / 30d / 3m / 1y)
- USD / INR currency toggle
